# Security and confidentiality

This repository contains confidential Shelly's Bistro project information, including financing assumptions, supplier pricing, operational plans, and summaries derived from private correspondence.

- Keep the GitHub repository **private**.
- Grant access only to approved team members.
- Do not copy credentials, OAuth tokens, mailbox exports, or `.env` files into the repository.
- Do not deploy the current prototype publicly. It is designed for local use and has no multi-user authentication or server-side authorization.
- Remove a former team member's GitHub access promptly when their project involvement ends.

If confidential information is committed accidentally, notify the repository owner immediately. Removing a file in a later commit does not remove it from Git history.
